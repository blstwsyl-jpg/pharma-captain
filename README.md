# صيدلي كابتن

تطبيق Expo مستقل للكباتن في منصة صيدلي.

## الوظائف الحالية

- حالة التوفر متاح/غير متاح.
- ملخص الطلبات الحالية والطلبات المتاحة من API المشترك.
- عرض التوصيل النشط والطلبات المرتبطة بحساب الكابتن.
- قبول الطلب وتغيير حالته حتى التسليم عبر API محمي.
- تحديث حالة التوفر في جدول الكباتن.
- تسجيل الدخول والخروج عبر OAuth مع صلاحية `captain`.
- شاشة الحساب والتقييم والمساعدة.
- RTL وهوية عربية مخصصة.

## التشغيل

```bash
pnpm install
pnpm dev
```

> يحتاج الحساب إلى دور `captain` وسجل في جدول `captains` حتى تظهر الطلبات الحية.
