# صيدلي كابتن

تطبيق Expo مستقل للكباتن في منصة صيدلي.

## الوظائف الحالية

- حالة التوفر متاح/غير متاح.
- ملخص توصيلات اليوم والأرباح.
- عرض التوصيل النشط.
- قائمة الطلبات القريبة.
- قبول الطلب وتغيير حالته محلياً.
- شاشة الحساب والتقييم والمساعدة.
- RTL وهوية عربية مخصصة.

## التشغيل

```bash
pnpm install
pnpm dev
```

> البيانات الحالية تجريبية حتى يتم ربط API المشترك مع لوحة الإدارة وتطبيق العميل.
